Backup Archiving

Configure file archival rules, encryption, and network constraints for backup operations.

Archive Geometry

Manage payload geometry for archival processes. Small files are packed into archives, standard files transfer continuously, and oversized files are split into fragments.

{% set tc = transfer_config %}

Small Assets

< {{ "%.0f"|format((tc.min_size_bytes / 1048576) if tc else 10) }} MiB

Packed into monolithic archives.

Standard Assets

{{ "%.0f"|format((tc.min_size_bytes / 1048576) if tc else 10) }} – {{ "%.0f"|format((tc.max_size_bytes / 1048576) if tc else 1024) }} MiB

Transferred continuously.

Oversize Assets

> {{ "%.0f"|format((tc.max_size_bytes / 1048576) if tc else 1024) }} MiB

Fragmented via multi-part upload.
Smaller files are packed together into shared archives.
Larger files are split into parts, none bigger than this. Minimum 64 MiB. Default 1024 MiB (1 GiB), so only files bigger than that are split.
A library or selection backup larger than this is split into several runs instead of one, so the worker never has to hold more than about this much compressed/encrypted data on local disk at a time. Doesn't limit a single file larger than this on its own.

Compression

Optionally gzip each file before it is encrypted and uploaded (standard gzip, so gunzip reads it). Files that are already compressed (video, most images and audio, zip-based documents) or that would shrink by less than 5% are stored as-is. Applies to new and changed files only - files already backed up are not re-uploaded, and existing backups restore exactly as before.

Higher is smaller but slower (default: 6)

Encryption Architecture

Applies AES-256-GCM derivation for all egress backups. Files receive distinct cryptographic keys bound to the core passphrase. Irrecoverable if every copy of the passphrase is lost.

Status: {% if backup_encryption_config and backup_encryption_config.enabled %} Active {% else %} Inactive {% endif %} {% if backup_encryption_config and backup_encryption_config.password %} {% endif %}
{% if key_versions %}
Key history:

Changing the passphrase keeps the old one here, and backups stay restorable with the key that encrypted them. Only new backups use the new key; unchanged files are not re-encrypted. Copy an old key if you need to decrypt outside MediaBridge.

{% endif %}
Advanced: portability (reconnect to another instance's encrypted backups)

A passphrase alone isn't the whole key - it's combined with a salt that's normally generated randomly when the passphrase is first set, so the same passphrase on a fresh instance makes a different key by default. The salt itself isn't secret (see docs/backup-plan/steps/18-portability.md), just needed alongside the passphrase to reproduce an existing key exactly - e.g. when moving to a new computer and pointing it at a bucket that already has encrypted backups.

{% if backup_encryption_config and backup_encryption_config.kdf_salt %}

Copy this (with the passphrase) before decommissioning this instance, so a new one can be reconnected.

{% endif %}
Must be paired with that same instance's passphrase above, or the reproduced key will be wrong and restores will fail.
